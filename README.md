# 🧠 Projet Prétraitement de Données

## 📌 Description
Ce projet a pour objectif de réaliser le prétraitement et l’analyse de données en utilisant Python et les bibliothèques de Data Science.  
Il permet de nettoyer les données, gérer les valeurs manquantes, transformer les colonnes et préparer les datasets pour les modèles de Machine Learning.

---

## 🚀 Technologies utilisées

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
